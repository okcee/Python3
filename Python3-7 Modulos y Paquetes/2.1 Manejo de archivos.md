## Manejo de Archivos en Python

El manejo de archivos en Python es una tarea fundamental para muchas aplicaciones. Python proporciona varias formas de interactuar con archivos, lo que permite leer, escribir y manipular datos almacenados en ellos.

**Operaciones básicas con archivos:**

1.  **Abrir un archivo:**
    * Se utiliza la función `open()` para abrir un archivo.
    * Requiere el nombre del archivo como argumento principal.
    * Opcionalmente, se puede especificar el modo de apertura:
        * `'r'`: Lectura (modo predeterminado). El archivo debe existir.
        * `'w'`: Escritura. Si el archivo no existe, se crea. Si existe, se sobrescribe.
        * `'a'`: Añadir (append). Si el archivo no existe, se crea. Si existe, el nuevo contenido se añade al final.
        * `'x'`: Creación exclusiva. Crea un nuevo archivo y falla si el archivo ya existe.
        * `'b'`: Modo binario. Se utiliza en combinación con otros modos (ej., `'rb'`, `'wb'`) para trabajar con archivos no textuales.
        * `'t'`: Modo texto (predeterminado).
        * `'+'`: Actualización (lectura y escritura). Se usa en combinación con otros modos (ej., `'r+'`, `'w+'`).
    * La función `open()` devuelve un objeto de archivo.

    ```python
    archivo = open("mi_archivo.txt", "r")  # Abre el archivo en modo lectura
    archivo_escritura = open("nuevo_archivo.txt", "w") # Abre en modo escritura
    ```

2.  **Leer desde un archivo:**
    * **`read()`:** Lee todo el contenido del archivo como una cadena.

        ```python
        contenido = archivo.read()
        print(contenido)
        ```
    * **`readline()`:** Lee una sola línea del archivo, incluyendo el carácter de nueva línea (`\n`) al final (si existe). En llamadas posteriores, continúa leyendo las siguientes líneas.

        ```python
        primera_linea = archivo.readline()
        print(primera_linea)
        segunda_linea = archivo.readline()
        print(segunda_linea)
        ```
    * **`readlines()`:** Lee todas las líneas del archivo y las devuelve como una lista de cadenas.

        ```python
        todas_las_lineas = archivo.readlines()
        for linea in todas_las_lineas:
            print(linea.strip()) # .strip() elimina espacios en blanco y el salto de línea
        ```
    * **Iterar sobre el objeto de archivo:** La forma más eficiente y Pythónica de leer un archivo línea por línea es iterar directamente sobre el objeto de archivo en un bucle `for`.

        ```python
        for linea in archivo:
            print(linea.strip())
        ```

3.  **Escribir en un archivo:**
    * **`write(cadena)`:** Escribe la cadena especificada en el archivo. No añade automáticamente un carácter de nueva línea.

        ```python
        archivo_escritura.write("Este es el contenido que se escribirá en el archivo.\n")
        archivo_escritura.write("Esta es otra línea.\n")
        ```
    * Para escribir múltiples líneas de forma más conveniente, se puede usar `writelines()` pasando una lista de cadenas.

        ```python
        lineas_a_escribir = ["Primera línea.\n", "Segunda línea.\n", "Tercera línea.\n"]
        archivo_escritura.writelines(lineas_a_escribir)
        ```

4.  **Cerrar un archivo:**
    * Es crucial cerrar un archivo después de terminar de trabajar con él para liberar los recursos del sistema y asegurar que los datos pendientes se escriban en el disco.
    * Se utiliza el método `close()`.

        ```python
        archivo.close()
        archivo_escritura.close()
        ```

**La sentencia `with`:**

* Para simplificar el manejo de archivos y asegurar que siempre se cierren, incluso si ocurren errores, se recomienda utilizar la sentencia `with`.
* La sentencia `with` gestiona automáticamente la apertura y el cierre del archivo.

    ```python
    with open("mi_archivo.txt", "r") as archivo:
        contenido = archivo.read()
        print(contenido)
    # El archivo se cierra automáticamente al salir del bloque 'with'

    with open("nuevo_archivo.txt", "w") as archivo_escritura:
        archivo_escritura.write("Contenido escrito usando 'with'.\n")
    ```

**Ejemplos prácticos:**

* **Leer un archivo y contar el número de líneas:**

    ```python
    with open("ejemplo.txt", "r") as archivo:
        num_lineas = 0
        for linea in archivo:
            num_lineas += 1
        print(f"El archivo tiene {num_lineas} líneas.")
    ```

* **Leer un archivo y escribir su contenido en otro archivo (en mayúsculas):**

    ```python
    with open("entrada.txt", "r") as archivo_entrada, open("salida.txt", "w") as archivo_salida:
        for linea in archivo_entrada:
            archivo_salida.write(linea.upper())
    print("El contenido de 'entrada.txt' en mayúsculas se ha escrito en 'salida.txt'.")
    ```

**Consideraciones importantes:**

* **Manejo de excepciones:** Al trabajar con archivos, pueden ocurrir errores (ej., el archivo no existe, permisos insuficientes). Es buena práctica utilizar bloques `try...except` para manejar estas situaciones de forma controlada.

    ```python
    try:
        with open("archivo_inexistente.txt", "r") as archivo:
            contenido = archivo.read()
            print(contenido)
    except FileNotFoundError:
        print("Error: El archivo no fue encontrado.")
    except IOError:
        print("Error de entrada/salida al leer el archivo.")
    ```

* **Codificación de caracteres:** Al leer o escribir archivos de texto, es importante tener en cuenta la codificación de caracteres (ej., UTF-8, Latin-1). Se puede especificar la codificación al abrir el archivo usando el parámetro `encoding`. UTF-8 es la codificación más recomendada para la mayoría de los casos.

    ```python
    with open("archivo_con_caracteres_especiales.txt", "r", encoding="utf-8") as archivo:
        contenido = archivo.read()
        print(contenido)

    with open("archivo_para_guardar.txt", "w", encoding="utf-8") as archivo:
        archivo.write("Texto con caracteres especiales como áéíóúñ.\n")
    ```

El manejo de archivos es una habilidad esencial en Python. Comprender las diferentes formas de abrir, leer, escribir y cerrar archivos, así como el uso de la sentencia `with` y el manejo de excepciones, te permitirá trabajar de manera efectiva con datos persistentes en tus programas.  

El modo `'a'` (append) se utiliza para abrir un archivo con el propósito de añadir nuevo contenido al final del mismo. Si el archivo no existe, se creará.

**Código de Ejemplo:**

```python
# Archivo al que queremos añadir contenido
nombre_archivo = "mi_archivo_existente.txt"

# Intentamos crear el archivo si no existe para el ejemplo
try:
    with open(nombre_archivo, "x") as archivo_creacion:
        archivo_creacion.write("Contenido inicial del archivo.\n")
    print(f"Archivo '{nombre_archivo}' creado.")
except FileExistsError:
    print(f"El archivo '{nombre_archivo}' ya existe.")

# Añadiendo contenido al archivo usando el modo 'a'
try:
    with open(nombre_archivo, "a") as archivo_append:
        archivo_append.write("Esta es la primera línea añadida.\n")
        archivo_append.write("Esta es la segunda línea añadida.\n")
    print(f"Se ha añadido contenido al archivo '{nombre_archivo}'.")
except IOError:
    print(f"Error al intentar escribir en el archivo '{nombre_archivo}'.")

# Verificando el contenido del archivo después de la operación append
try:
    with open(nombre_archivo, "r") as archivo_lectura:
        print("\nContenido actual del archivo:")
        for linea in archivo_lectura:
            print(linea, end='') # Usamos end='' para evitar doble salto de línea
except FileNotFoundError:
    print(f"Error: El archivo '{nombre_archivo}' no fue encontrado para lectura.")
except IOError:
    print(f"Error al intentar leer el archivo '{nombre_archivo}'.")
