## Categorías de Mandatos SQL

SQL tiene tres categorías principales de mandatos o lenguajes que permiten la creación, mantenimiento y utilización de bases de datos:

### 1) Lenguaje de Definición de Datos (DDL)

Los desarrolladores web utilizan los mandatos de definición de datos para crear y definir bases de datos y tablas de datos.

* **CREATE:** Crea bases de datos, tablas y otros objetos de la base de datos.
* **ALTER:** Modifica la estructura de bases de datos o tablas existentes (ej., añadir o eliminar columnas).
* **DROP:** Elimina tablas u otros objetos existentes de una base de datos.

### 2) Lenguaje de Manipulación de Datos (DML)

Los desarrolladores web utilizan mandatos de manipulación de datos para modificar los datos dentro de las tablas de una base de datos. Estos mandatos a menudo se relacionan con las operaciones CRUD (Create, Read, Update, Delete).

* **INSERT:** Añade nuevos registros a una tabla (corresponde a la operación **Create** de CRUD).
* **UPDATE:** Modifica registros existentes en una tabla.
* **DELETE:** Elimina registros de una tabla.

### 3) Lenguaje de Consulta de Datos (DQL)

Los desarrolladores web utilizan mandatos de consulta de datos para recuperar información de las tablas en una base de datos.

* **SELECT:** Muestra el contenido de una tabla (corresponde a la operación **Read** de CRUD).
