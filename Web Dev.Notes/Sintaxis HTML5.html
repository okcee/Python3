Sintaxis HTML5 - Ejemplos de Etiquetas

A continuación, se presenta una lista de ejemplos de sintaxis HTML5, mostrando diversas etiquetas y su uso:

  • <!DOCTYPE html>

    Define el tipo de documento como HTML5.

  • <html>

    Etiqueta raíz del documento HTML. Contiene todo el contenido de la página.

  • <head>

    Contiene metadatos del documento, como el título, la codificación de caracteres, etc.

  • <body>

    Contiene el contenido visible de la página web.

  • <title>Título de la página</title>

    Define el título de la página que se muestra en la barra de título del navegador.

  • <meta charset="UTF-8">

    Define la codificación de caracteres del documento, en este caso UTF-8.

  • <h1>Encabezado de nivel 1</h1>

    Define un encabezado de nivel 1. Se pueden usar h1 hasta h6.

  • <p>Párrafo de texto</p>

    Define un párrafo de texto.

  • <a href="https://www.ejemplo.com">Enlace</a>

    Define un enlace a otra página web o recurso.

  • <img src="imagen.jpg" alt="Descripción de la imagen">

    Define una imagen. El atributo "src" especifica la ruta de la imagen y "alt" proporciona una descripción alternativa.

  • <ul>

    Define una lista desordenada (con viñetas).

  • <ol>

    Define una lista ordenada (numerada).

  • <li>Elemento de la lista</li>

    Define un elemento dentro de una lista (ya sea ordenada o desordenada).

  • <div>Contenedor genérico</div>

    Define un contenedor genérico para agrupar elementos.

  • <span>Texto en línea</span>

    Define un contenedor en línea para aplicar estilos a una parte específica del texto.

  • <em>Etiqueta de énfasis</em>

    Etiqueta de énfasis (generalmente se muestra en cursiva).

  • <strong>Texto importante</strong>

    Define texto importante (generalmente se muestra en negrita).

  • <br>

    Inserta un salto de línea.

  • <hr>

    Inserta una línea horizontal.

  • <table>

    Define una tabla.

  • <tr>

    Define una fila dentro de una tabla.

  • <td>

    Define una celda dentro de una fila de la tabla.

  • <th>

    Define una celda de encabezado dentro de una fila de la tabla.

  • <form>

    Define un formulario para la entrada de datos.

  • <input>

    Define un campo de entrada dentro de un formulario (texto, número, etc.).

  • <label>

    Define una etiqueta para un campo de entrada.

  • <button>

    Define un botón.

  • <textarea>

    Define un área de texto para la entrada de texto multilínea.

  • <header>

    Define la cabecera de una sección o de la página.

  • <nav>

    Define una sección de navegación.

  • <main>

    Define el contenido principal de la página.

  • <section>

    Define una sección dentro del documento.

  • <article>

    Define un artículo independiente.

  • <aside>

    Define contenido secundario o complementario.

  • <footer>

    Define el pie de página de una sección o de la página.

  • <video>

    Define un video.

  • <audio>

    Define un audio.
