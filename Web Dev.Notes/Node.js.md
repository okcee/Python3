Las solicitudes de páginas web contactan con un servidor web principalmente en dos puertos: 80 para solicitudes http y 443 para solicitudes https.  

Un problema que resuelve Node.js es la eficiencia del proceso de solicitudes. Muchos servidores web consumen muchos recursos informáticos, especialmente cuando reciben muchas solicitudes. Como entorno de ejecución, Node.js está diseñado para manejar muchas solicitudes de forma rápida y eficiente.  

Existe una herramienta denominada Gestor de paquetes de nodo (MNP) para obtener las bibliotecas para Node.js creadas por otros desarrolladores.  

NPM, es un paquete de software que busca, recupera e instala software de su catálogo. Los desarrolladores web pueden ampliar Node.js y otras herramientas de desarrollo web utilizando un amplio catálogo de software de código abierto.  

Los paquetes de software que instala utilizando NPM se denominan marcos y bibliotecas. Los tipos de software a los que serefieren estos dos términos son similares pero tienen diferencias significativas.  
Estas son algunas diferencias entre una biblioteca y un marco:  
- Las bibliotecas tienden a tener una función más limitada. Por ejemplo, un desarrollador podría utilizar una biblioteca JavaScript para mejorar la navegación en el DOM HTML. Esto amplía lo que JavaScript ya hace y añade más características. Los marcos tienden a añadir nuevas características que el JavaScript nativo no tiene.
- Las bibliotecas no utilizan marcos, pero los marcos utilizan bibliotecas. Algunos marcos, como React, utilizan la biblioteca jQuery. Una herramienta o código que necesita otra herramienta o código para su ejecución se considera una dependencia. Las bibliotecas no dependen de los marcos.
- Los desarrolladores llaman al código en una biblioteca cuando necesitan utilizar una función de la biblioteca, o bajo demanda. Por otro lado, integrarán un marco en todo el sitio web, el cual cambiará el funcionamiento del sitio web.

Muchos sitios web importantes utilizan y modifican marcos como Vue.js, Angular y React para manejar el proceso de datos y proporcionar a los sitios un aspecto y un comportamiento con los que los usuarios ya están familiarizados. jQuery, una biblioteca que ayuda a buscar elementos y modificarlos en el DOM HTML, es una biblioteca popular que se utiliza en toda la web.
