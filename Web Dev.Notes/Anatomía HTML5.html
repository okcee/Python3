La declaración DOCTYPE es . Esta declaración describe la versión de HTML que se está utilizando. El elemento HTML es . Este elemento envuelve todos los demás elementos en una página. Define el tipo de documento (un documento HTML) que lee el analizador. El elemento de cabecera es . Este elemento define otros recursos, como metadatos, scripts y estilos que utiliza la página HTML. Normalmente, el usuario no percibe directamente lo que contiene el elemento de cabecera. El elemento del cuerpo es . Este elemento es donde se colocará la mayor parte del contenido de la página. Los elementos de esta sección pueden utilizar recursos como scripts y estilos definidos en la sección de cabecera.
