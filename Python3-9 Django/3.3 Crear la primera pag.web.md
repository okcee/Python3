# Guía Paso a Paso para Crear una Página Web Compleja con Django y PostgreSQL

Esta guía te llevará a través del proceso de creación de una página web compleja utilizando Django y PostgreSQL, siguiendo la estructura de tu proyecto. 

### Estructura del proyecto Django

A continuación de muestra el esquema de directorios del proyecto Django:  

workspace/
└── Python3/ # Raíz del workspace
├── PYworld/ # Directorio del proyecto principal
│ ├── PYworld_Apps/ # Directorio para aplicaciones específicas
│ └── PYworld/
│ └── settings.py # Archivo de configuración del proyecto
└── .virtEnv/ # Entorno virtual del proyecto

Descripción de los elementos:  

- **workspace**: `/Python3`  
  Es el directorio raíz donde se encuentra todo el proyecto.

- **proyecto**: `/Python3/PYworld`  
  Contiene el código fuente principal del proyecto.

- **Apps**: `/Python3/PYworld/PYworld_Apps`  
  Directorio dedicado a almacenar aplicaciones específicas del proyecto.

- **entorno virtual**: `/Python3/.virtEnv`  
  Directorio oculto que contiene el entorno virtual del proyecto.

- **settings.py**: `/Python3/PYworld/PYworld/settings.py`  
  Archivo de configuración principal del proyecto.

## 1. Configuración de Django para PostgreSQL

Una vez que se ha:  
- Instalado PostgreSQL.
- Configurado PostgreSQL.
- Creado la base de datos.
- Opcional pero recomendable por seguridad: Crear archivo `.env` y configurarlo (Directorio raíz del proyecto).
- Crea el archivo .gitignore (Directorio raíz del proyecto).

1.1. Modifica el archivo **PYworld/PYworld/settings.py** para utilizar PostgreSQL. Asegúrate de que tu configuración de la base de datos se vea así:  
```python
import os
from dotenv import load_dotenv

load_dotenv()

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': os.getenv('DATABASE_NAME'),
        'USER': os.getenv('DATABASE_USER'),
        'PASSWORD': os.getenv('DATABASE_PASSWORD'),
        'HOST': os.getenv('DATABASE_HOST'),
        'PORT': os.getenv('DATABASE_PORT'),
    }
}
```
1.2. Instala el paquete python-dotenv:  

Abre tu terminal o línea de comandos, activa tu entorno virtual y ejecuta el siguiente comando:  
```Bash
pip install python-dotenv
```
Verifica la instalación:  
```Bash
pip list
```
Reinicia VS Code

## 2. Creación de la Aplicación PYworld_Apps

Una vez que se ha creado la Aplicación PYworld_Apps.

### 2.1 Creación del Modelo (models.py)

Define tus modelos en el archivo `PYworld_Apps/models.py`. Por ejemplo, vamos a crear un modelo `Producto`:  
```python
from django.db import models

class Producto(models.Model):
    nombre = models.CharField(max_length=200)
    descripcion = models.TextField()
    precio = models.DecimalField(max_digits=10, decimal_places=2)
    fecha_creacion = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.nombre
```

### 2.2 Creación de Vistas (views.py)

Crea tus vistas en el archivo `PYworld_Apps/views.py`. Por ejemplo, vamos a crear una vista para mostrar todos los productos:  
```python
from django.shortcuts import render
from .models import Producto

def lista_productos(request):
    productos = Producto.objects.all()
    return render(request, 'PYworld_Apps/lista_productos.html', {'productos': productos})
```

### 2.3 Creación de URLs (urls.py)

Crea un archivo `urls.py` dentro de la carpeta `PYworld_Apps` y define tus URLs:
```python
from django.urls import path
from . import views

urlpatterns = [
    path('productos/', views.lista_productos, name='lista_productos'),
]
```

### 2.4 Creación de Plantillas (templates)

Crea una carpeta `templates` dentro de `PYworld_Apps` y dentro una carpeta con el nombre de la app, y crea tus plantillas HTML. Por ejemplo, crea `lista_productos.html`:  
```html
<!DOCTYPE html>
<html>
<head>
    <title>Lista de Productos</title>
</head>
<body>
    <h1>Lista de Productos</h1>
    <ul>
        {% for producto in productos %}
            <li>{{ producto.nombre }} - ${{ producto.precio }}</li>
        {% endfor %}
    </ul>
</body>
</html>
```

### 2.5 Creación de Pruebas (tests.py)

Escribe pruebas para tu aplicación en el archivo `PYworld_Apps/tests.py`.  

### 2.6 Configuración de la Aplicación (apps.py)

Asegúrate de que la configuración de tu aplicación en `PYworld_Apps/apps.py` sea correcta.

## Registro de la Aplicación y sus Módulos

### 3.1 Registro de la Aplicación

Añade `PYworld_Apps` a `INSTALLED_APPS` en `PYworld/PYworld/settings.py`:  
```Python
INSTALLED_APPS = [
    'PYworld_Apps',
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
]
```

### 3.2 Inclusión de URLs de la Aplicación

Incluye las URLs de tu aplicación en `PYworld/PYworld/urls.py`:  
```Python
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('productos/', include('PYworld_Apps.urls')),
    path('admin/', admin.site.urls),
]
```

### 3.3 Configuración del Archivo `.gitignore`

Asegúrate de que tu archivo .gitignore incluya los siguientes directorios y archivos:

.virtEnv/
*.pyc
__pycache__/
.env
db.sqlite3

### 3.4 Migraciones

Ejecuta las migraciones para crear las tablas en la base de datos:
Deben ejecutarse desde el directorio donde se encuentra el archivo manage.py de tu proyecto Django
```Bash
python manage.py makemigrations
python manage.py migrate
```

### 3.5 Ejecución del Servidor

Ejecuta el servidor de desarrollo:
Debe ejecutarse desde el directorio donde se encuentra el archivo manage.py de tu proyecto Django
```Bash
python manage.py runserver
```
