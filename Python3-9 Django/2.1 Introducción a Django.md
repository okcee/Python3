# Introducción a Django

## ¿Qué es Django?
- **Framework web de alto nivel** escrito en Python.
- No es un CMS (Content Management System = Sistema de Gestión de Contenidos), sino una herramienta para construir sitios web desde cero.
- Licencia BSD: gratuito y de código abierto.
- Fomenta el desarrollo rápido, diseño limpio y pragmático.
- Proporciona estructura para desarrollar aplicaciones web rápidas y seguras.

### Características principales:
- Plantilla de diseño sólida.
- Sistema de gestión de bases de datos robusto.
- Herramienta de administración de contenido.
- Escalable y seguro.
- Amplia documentación y comunidad.

---

## ¿Qué puedes hacer con Django?
1. **Crear aplicaciones web rápidamente**:
   - Incluye componentes comunes como autenticación, gestión de bases de datos y sistema de plantillas.
2. **Escalabilidad**:
   - Diseñado para manejar miles de solicitudes simultáneas.
3. **Seguridad**:
   - Protege contra ataques como inyecciones SQL y cross-site scripting.
   - Cumple con regulaciones como GDPR.
4. **Reutilización de código**:
   - Sigue los principios DRY (Don’t Repeat Yourself).

---

## Arquitectura MVT
Django utiliza un patrón similar al MVC (Modelo-Vista-Controlador), llamado **MVT**:
- **Model**: Gestiona los datos y la interacción con la base de datos.
- **Template**: Define cómo se muestra la información al usuario.
- **View**: Actúa como intermediario entre el modelo y la plantilla.

---

## ¿Quién utiliza Django?
- **Empresas**: Instagram, Spotify, Dropbox.
- **Startups**: Ideal para proyectos escalables.
- **Desarrolladores independientes**: Popular por su comunidad y documentación.
- **Instituciones educativas**: Usado para enseñanza de programación.
- **Organizaciones sin fines de lucro**: Sitios web de bajo costo y alta calidad.

---

## ¿Por qué usar Django?
- Ideal para aplicaciones altamente personalizables (ej. redes sociales).
- Gran soporte comunitario y complementos personalizables.
- Escalable, seguro y flexible.
- Adecuado para proyectos complejos que requieren personalización.

---

## Django vs WordPress
| **Característica**       | **Django**                                   | **WordPress**                              |
|--------------------------|---------------------------------------------|-------------------------------------------|
| **Propósito**            | Construir aplicaciones web complejas.       | Crear blogs y sitios web pequeños.        |
| **Personalización**      | Alta.                                       | Limitada (depende de plugins).            |
| **Programación**         | Requiere conocimientos de programación.     | No requiere programación.                 |
| **Escalabilidad**        | Ideal para proyectos grandes.               | Mejor para proyectos pequeños o medianos. |

---

## Conclusión
Django es una herramienta poderosa para desarrolladores que buscan crear aplicaciones web complejas, escalables y seguras. Su filosofía de desarrollo rápido, junto con su gran comunidad y documentación, lo convierten en una opción popular para proyectos personalizados.  

## Los gestores de bases de datos soportados oficialmente por Django son:
- SQLite3: Gestor de BBDD por defecto.
- PostgreSQL: Gestor recomendado.
- MySQL
- Oracle

Para sistemas gestores de bases de datos que no están por defecto incluidos en Django (como SQL server, SAP SQL, etc) existen en internet “conectores” que permiten a Django trabajar con prácticamente cualquier BBDD.  

Algunos conectores ofrecidos por terceros son:  
- SQL Server
- SAP SQL
- Firebird
