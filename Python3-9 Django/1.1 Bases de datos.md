# Introducción a las Bases de Datos

## Lenguaje SQL
El lenguaje más común para interactuar con bases de datos es el **SQL (Structured Query Language)**. Permite crear, modificar y consultar datos almacenados en una base de datos.

### Sistemas de Gestión de Bases de Datos (DBMS)
- Los DBMS administran y controlan el acceso a los datos.
- Ejemplos: Oracle, Microsoft SQL Server, MySQL, PostgreSQL.
- Proporcionan funciones de seguridad para restringir el acceso a usuarios autorizados.

---

## Tipos de Bases de Datos

1. **Bases de datos relacionales**  
   - Más comunes.
   - Basadas en el modelo relacional con tablas, filas y columnas.
   - Las tablas están relacionadas mediante claves externas.

2. **Bases de datos no relacionales**  
   - Alternativa a las relacionales.
   - Usadas cuando los datos no encajan en tablas y filas.
   - Ejemplos:
     - Bases de datos en memoria.
     - Bases de datos orientadas a documentos.
     - Bases de datos gráficas.

3. **Bases de datos en memoria**  
   - Almacenan datos en la RAM, lo que las hace rápidas pero limitadas en tamaño y durabilidad.

4. **Bases de datos orientadas a documentos**  
   - Almacenan datos en forma de documentos.
   - Cada documento representa una entidad única con campos y anidamientos variables.

5. **Bases de datos gráficas**  
   - Representan información como grafos con nodos y relaciones.
   - Útiles para estructuras complejas y cambiantes.

---

## Componentes Básicos de las Bases de Datos

1. **Datos**  
   - Organizados en tablas con filas y columnas.
   - Cada columna representa un atributo.

2. **DBMS**  
   - Software para administrar y controlar el acceso a los datos.
   - Permite crear, modificar, borrar y consultar datos.

3. **Usuario**  
   - Personas o programas que interactúan con la base de datos.

4. **Hardware**  
   - Componente físico: servidores, almacenamiento en disco y red.

5. **Reglas de integridad**  
   - Garantizan coherencia y consistencia de los datos.

6. **Índices**  
   - Optimizan el acceso a los datos mediante mapas rápidos.

7. **Consultas**  
   - Solicitudes para acceder a los datos, desde simples hasta complejas.

8. **Transacciones**  
   - Operaciones seguras para modificar o actualizar datos.

9. **Seguridad**  
   - Medidas como autenticación, control de acceso y encriptación.

10. **Backup y recuperación**  
    - Copias de seguridad para proteger los datos ante fallos.

11. **Replicación**  
    - Mantener copias idénticas en múltiples servidores para mejorar disponibilidad.

12. **Escalabilidad**  
    - Capacidad para manejar más datos y usuarios sin perder rendimiento.

13. **Gestión del rendimiento**  
    - Optimización para garantizar alto rendimiento y disponibilidad.

14. **Control de versiones**  
    - Historial de versiones anteriores para precisión y reversión en caso de errores.
