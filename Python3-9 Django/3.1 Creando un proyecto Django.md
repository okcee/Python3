# Creación de un Proyecto Django

Este documento resume los pasos iniciales para crear un proyecto Django, basándose en la información proporcionada.

## Instalación de Django: Local vs. Entorno Virtual

Django puede instalarse de forma local o dentro de un entorno virtual. Se recomienda la instalación en un entorno virtual por las siguientes ventajas:

* **Control de versiones:** Permite especificar y mantener versiones consistentes de Python y Django para cada proyecto, evitando problemas de incompatibilidad entre proyectos.
* **Gestión de dependencias:** Las dependencias (otras bibliotecas de Python necesarias para el proyecto) se instalan específicamente para ese entorno virtual, sin afectar a otros proyectos ni a la instalación global de Python.
* **Entornos aislados:** Facilita la creación de entornos separados para desarrollo, pruebas y producción, permitiendo probar cambios en un entorno aislado antes de implementarlos en producción.
* **Colaboración:** Asegura que todos los desarrolladores trabajen con las mismas versiones de software, simplificando la colaboración y reduciendo errores.

Aunque la guía indica que el primer proyecto se realizará con Django instalado localmente, **se recomienda encarecidamente utilizar entornos virtuales para proyectos reales**. Las herramientas comunes para crear y gestionar entornos virtuales en Python incluyen `venv` (incorporado en Python) y `conda`.

## Bases de Datos Soportadas por Django

Django soporta oficialmente los siguientes gestores de bases de datos:

* **SQLite3:** Es el gestor de bases de datos por defecto. Es ligero y no requiere configuración adicional, lo que lo hace ideal para empezar y para proyectos pequeños o de desarrollo. Viene incluido en las últimas versiones de Python.
* **PostgreSQL:** Es el gestor recomendado por Django por su robustez, funcionalidades y rendimiento.
* **MySQL**
* **Oracle**

Para otros gestores de bases de datos no soportados directamente, existen **conectores de terceros** que permiten la integración con Django (por ejemplo, SQL Server, SAP SQL, Firebird).

## Creando el Primer Proyecto Django (Local)

Para crear un nuevo proyecto Django, sigue estos pasos:

1.  **Abre la terminal o línea de comandos.**
2.  **Navega hasta la carpeta de trabajo** donde deseas crear el proyecto.
3.  **Ejecuta el siguiente comando:**
    ```bash
    django-admin startproject miProyecto
    ```
    Reemplaza `miProyecto` con el nombre que quieras darle a tu proyecto.

4.  **Se creará una carpeta llamada `miProyecto`** con la estructura de archivos inicial necesaria para tu proyecto Django.

## Estructura del Proyecto

Dentro de la carpeta del proyecto (`miProyecto`), encontrarás los siguientes archivos y carpetas importantes:

* **`manage.py`:** Una utilidad de línea de comandos que permite interactuar con el proyecto Django para realizar diversas tareas (ejecutar el servidor de desarrollo, crear aplicaciones, ejecutar migraciones, etc.).
* **`miProyecto/` (carpeta interior):** Un paquete de Python que contiene los archivos de configuración del proyecto:
    * **`__init__.py`:** Un archivo vacío que indica a Python que este directorio debe ser tratado como un paquete.
    * **`settings.py`:** Contiene todas las configuraciones del proyecto Django, incluyendo la configuración de la base de datos, las aplicaciones instaladas, la configuración de las URLs, etc.
    * **`urls.py`:** Define las rutas (URLs) de la aplicación y las vistas (funciones que procesan las peticiones a esas URLs) asociadas.
    * **`wsgi.py`:** Un archivo necesario para desplegar la aplicación Django en un servidor web compatible con WSGI (Web Server Gateway Interface).

## Configuración Inicial de la Base de Datos

Por defecto, Django utiliza SQLite3. Para crear la base de datos inicial, navega hasta la carpeta raíz de tu proyecto (`miProyecto` donde se encuentra `manage.py`) y ejecuta el siguiente comando:

```bash
python manage.py migrate
```
