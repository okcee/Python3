maquina_snacks_proyecto.maquina_snacks_app: Le dice a Python que busque el módulo maquina_snacks_app dentro del paquete maquina_snacks_proyecto. Como maquina_snacks_proyecto tiene el archivo __init__.py, Python lo reconoce como un paquete.
