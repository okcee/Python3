# Sintaxis Completa de una Clase en Python

**Clase**: Es la plantilla o el diseño. Define qué atributos tendrán los objetos de esa clase y qué acciones podrán realizar (métodos). Imagina una clase como un plano para construir objetos. Aquí tienes la estructura general con todas las partes posibles:  

```python
class NombreDeLaClase(ClasePadre1, ClasePadre2, ...):
    """
    Documentación de la clase: Describe el propósito y funcionamiento de la clase.
    """

    # Atributos de clase (compartidos por todas las instancias de la clase)
    variable_de_clase = valor_inicial

    # Método constructor (se llama al crear una nueva instancia)
    def __init__(self, parametro1, parametro2, ...):
        """
        Documentación del método __init__. Inicializa los atributos del objeto.
        """
        # Atributos de instancia (propios de cada objeto)
        self.atributo1 = parametro1
        self.atributo2 = parametro2
        # ... otras inicializaciones

    # Otros métodos de instancia (acciones que los objetos pueden realizar)
    def metodo1(self, otro_parametro):
        """
        Documentación del método metodo1. Describe lo que hace este método.
        """
        # Lógica del método
        resultado = self.atributo1 + otro_parametro
        return resultado

    def metodo2(self):
        """
        Documentación del método metodo2.
        """
        # ... más lógica

    # Métodos de clase (operan sobre la clase en sí misma)
    @classmethod
    def metodo_de_clase(cls, argumento):
        """
        Documentación del método de clase.
        """
        # Lógica del método de clase (usa 'cls' en lugar de 'self')
        return cls.variable_de_clase + argumento

    # Métodos estáticos (asociados a la clase pero no acceden a sus atributos ni a la instancia)
    @staticmethod
    def metodo_estatico(parametro):
        """
        Documentación del método estático.
        """
        # Lógica del método estático
        return "Resultado: " + str(parametro)

    # Métodos especiales (con nombres predefinidos que Python utiliza para ciertas operaciones)
    def __str__(self):
        """
        Define cómo se representa el objeto como una cadena (para print()).
        """
        return f"Objeto de la clase {self.__class__.__name__} con atributo1: {self.atributo1}"

    def __repr__(self):
        """
        Define una representación "oficial" del objeto (para desarrollo y debugging).
        """
        return f"<{self.__class__.__name__}(atributo1={self.atributo1}, atributo2={self.atributo2})>"

    # ... otros métodos especiales como __len__, __getitem__, __setitem__, etc.
```

**Desglosando los elementos:**

- `class NombreDeLaClase(ClasePadre1, ClasePadre2, ...):`
  - `class`: Palabra clave para definir una clase.
  - `NombreDeLaClase`: El nombre que le das a tu clase (por convención, empieza con mayúscula y usa CamelCase).
  - `(ClasePadre1, ClasePadre2, ...)`: Herencia opcional. Si tu clase hereda de otras clases, las colocas entre paréntesis separadas por comas. Si no hereda de ninguna, simplemente omite los paréntesis.

- `"""Documentación de la clase..."""`: Un docstring (cadena de documentación) que explica qué hace la clase. ¡Es muy importante para que otros (y tú mismo en el futuro) entiendan tu código!

- `variable_de_clase = valor_inicial`: Un atributo que pertenece a la clase en sí misma. Todas las instancias (objetos) de esta clase compartirán el mismo valor de este atributo (a menos que una instancia lo modifique a nivel individual).

- `def __init__(self, parametro1, parametro2, ...)`: El constructor. Este método especial se llama automáticamente cuando creas un nuevo objeto de la clase.
  - `self`: Es una referencia a la instancia del objeto que se está creando. Es el primer parámetro de la mayoría de los métodos de instancia.
  - `parametro1, parametro2, ...`: Son los parámetros que puedes pasar al crear un objeto de la clase.
  - Dentro de `__init__`, generalmente inicializas los atributos de instancia usando `self.atributo = valor`. Estos atributos son específicos de cada objeto.

- `def metodo1(self, otro_parametro)`: Un método de instancia. Son funciones que pertenecen a la clase y operan sobre una instancia específica (un objeto). Siempre tienen `self` como su primer parámetro.

- `@classmethod def metodo_de_clase(cls, argumento)`: Un método de clase. Se define con el decorador `@classmethod`.
  - `cls`: Es una referencia a la clase en sí misma (similar a `self`, pero para la clase).
  - Los métodos de clase pueden acceder y modificar los atributos de clase, pero no directamente los atributos de instancia.

- `@staticmethod def metodo_estatico(parametro)`: Un método estático. Se define con el decorador `@staticmethod`.
  - No reciben ni `self` ni `cls` como primer parámetro.
  - Son como funciones regulares que están dentro del espacio de nombres de la clase porque lógicamente están relacionadas con ella, pero no operan sobre la clase ni sobre ninguna instancia en particular.

- `def __str__(self)`: Un método especial que define cómo se representa un objeto como una cadena cuando usas la función `print()` o lo conviertes a `str()`.

- `def __repr__(self)`: Otro método especial que define una representación "oficial" del objeto. Es útil para debugging y cuando el objeto se muestra en colecciones (listas, diccionarios). Idealmente, la representación debería ser una cadena que, al ser evaluada con `eval()`, recree el objeto (si es posible).

- **Otros métodos especiales**: Python tiene muchos otros métodos especiales (también llamados "dunder methods" porque tienen doble guion bajo al principio y al final) que te permiten personalizar el comportamiento de tus objetos para operaciones como la longitud (`__len__`), el acceso por índice (`__getitem__`, `__setitem__`), comparaciones (`__eq__`, `__lt__`), operaciones aritméticas (`__add__`, `__sub__`), etc.
