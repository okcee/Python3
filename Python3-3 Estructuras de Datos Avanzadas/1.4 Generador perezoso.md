# Generadores: Iteración Perezosa y Eficiente

Imagina que tienes que trabajar con una secuencia muy larga de números, quizás millones o incluso infinitos. Si intentaras crear una lista con todos esos números de una vez, tu programa podría quedarse sin memoria y volverse muy lento.

Aquí es donde entran en juego los **generadores**. Un generador es una forma especial de crear iteradores de manera sencilla y eficiente. La clave de su eficiencia radica en que no generan todos los valores de la secuencia de inmediato, sino que los producen uno a uno, bajo demanda. A esto se le llama **evaluación perezosa** o **lazy evaluation**.

---
## ¿Cómo se crean los generadores?

Hay dos formas principales de crear generadores en Python:

### 1. Funciones generadoras

Son funciones que utilizan la palabra clave `yield` en lugar de `return`. Cuando se llama a una función generadora, no se ejecuta el código de inmediato. En su lugar, devuelve un objeto generador (que es un tipo especial de iterador). El código de la función se pausa en el punto donde se encuentra `yield`, y el valor que se especifica después de `yield` es el que se "produce" en esa iteración. La próxima vez que se pide otro valor al generador, la ejecución de la función se reanuda justo después del `yield` anterior.

```python
def generador_pares(limite):
    numero = 0
    while numero <= limite:
        yield numero
        numero += 2

# Creamos un objeto generador
pares = generador_pares(10)

# Podemos iterar sobre él con un bucle for
print("Iterando con for:")
for par in pares:
    print(par)

# También podemos obtener los valores uno a uno con next()
pares_otra_vez = generador_pares(4)
print("\nIterando con next():")
print(next(pares_otra_vez))  # Output: 0
print(next(pares_otra_vez))  # Output: 2
print(next(pares_otra_vez))  # Output: 4
# print(next(pares_otra_vez))  # Generaría StopIteration
```

#### Puntos clave sobre las funciones generadoras:

- La presencia de `yield` convierte una función en un generador.
- Cuando se llama a la función, se devuelve un objeto generador, no se ejecuta el cuerpo de la función inmediatamente.
- Cada vez que se encuentra un `yield`, la función pausa su ejecución y devuelve el valor.
- La próxima vez que se pide un valor, la ejecución se reanuda desde donde se quedó.
- Cuando la función termina (ya sea llegando al final o con una sentencia `return` sin valor), el generador eleva la excepción `StopIteration`, indicando que no hay más valores.

---
### 2. Expresiones generadoras

Son una forma concisa de crear generadores, similar a las comprensiones de listas, pero utilizando paréntesis `()` en lugar de corchetes `[]`.

```python
cuadrados = (x ** 2 for x in range(5))

print("Iterando con una expresión generadora:")
for cuadrado in cuadrados:
    print(cuadrado)

# También se puede convertir a una lista (pero ¡cuidado! esto puede consumir memoria si el rango es grande)
cuadrados_lista = list(x ** 2 for x in range(5))
print("\nLista desde expresión generadora:", cuadrados_lista)
```

#### Puntos clave sobre las expresiones generadoras:

- Son más compactas que las funciones generadoras para casos sencillos.
- También producen iteradores perezosos.
- Son especialmente útiles cuando el generador se va a utilizar una sola vez.

---
## Ventajas de usar generadores

1. **Eficiencia de memoria**: Los generadores solo almacenan el estado necesario para producir el siguiente valor, no toda la secuencia en memoria. Esto es crucial para trabajar con grandes conjuntos de datos o secuencias infinitas.
2. **Rendimiento mejorado (en algunos casos)**: La generación de valores bajo demanda puede ser más rápida que generar y almacenar toda la secuencia de antemano, especialmente si no necesitas todos los elementos.
3. **Código más limpio y legible**: Para ciertas tareas de iteración compleja, los generadores pueden simplificar la lógica y hacer el código más fácil de entender.
4. **Posibilidad de representar secuencias infinitas**: Como los valores se generan bajo demanda, puedes crear generadores que conceptualmente representan secuencias infinitas (aunque en la práctica solo se producirán los valores que se necesiten).

```python
def generador_infinito_de_unos():
    while True:
        yield 1

unos = generador_infinito_de_unos()
print(next(unos))  # Output: 1
print(next(unos))  # Output: 1
# Esto continuaría indefinidamente...
```

---
## Cuándo usar generadores

- Cuando trabajas con grandes conjuntos de datos que no caben en la memoria.
- Cuando necesitas generar una secuencia de valores de forma perezosa.
- Cuando la lógica para generar la siguiente secuencia de valores es compleja.
- Para implementar tuberías de procesamiento de datos donde los elementos se procesan uno a la vez.

---
## En resumen:

Los generadores son una herramienta poderosa en Python para la iteración eficiente. Permiten crear iteradores de forma sencilla utilizando funciones con `yield` o expresiones generadoras. Su principal ventaja es la eficiencia en el uso de la memoria, ya que los valores se generan bajo demanda.
