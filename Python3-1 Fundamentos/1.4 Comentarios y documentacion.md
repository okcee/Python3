# Comentarios de una línea (#)

Son ideales para explicar una línea de código o añadir una nota rápida. Todo lo que escribas después del símbolo `#` en una línea será ignorado por Python.  
`# Esto es un comentario de una línea`  
`variable = 10  # Aquí estamos asignando el valor 10 a la variable`  

# Comentarios de varias líneas ("""Docstring""" o '''Docstring''')

Se utilizan para bloques de texto más largos. Aunque técnicamente son string literals (cadenas de texto), se usan comúnmente para escribir documentación dentro de tu código, especialmente para funciones, clases y módulos. Se encierran entre tres comillas dobles (`"""`) o tres comillas simples (`'''`).  

```
"""
Este es un comentario de varias líneas.
Se puede usar para explicar un bloque de código más extenso
o para documentar una función.
"""
def mi_funcion(parametro):
    """
    Esta función toma un parámetro y lo imprime.

    Args:
        parametro: El valor que se va a imprimir.
    """
    print(parametro)
```

A estos comentarios de varias líneas utilizados para documentación se les llama **docstrings**. Son muy importantes porque muchas herramientas de Python pueden leerlos automáticamente para generar documentación de tu proyecto.  

# Docstrings

- Los docstrings son la forma estándar de documentar tu código Python.
- Se definen como la primera cadena multilínea dentro de módulos, funciones, clases y métodos.
- Son accesibles mediante el atributo `__doc__` y la función `help()`.
- Son fundamentales para la claridad, la documentación automática y la mantenibilidad del código.

## Docstrings: La Documentación Integrada

Como te mencioné antes, los docstrings son cadenas de texto multilínea (usando `""" """` o `''' '''`) que se colocan como la primera instrucción dentro de un módulo, función, clase o método. La gran ventaja de los docstrings es que Python los almacena y los hace accesibles en tiempo de ejecución.  
Se usan al principio de un módulo (.py): Para describir el propósito general del archivo, los principales componentes que contiene y cómo se utiliza.  

```
"""
Este módulo contiene funciones para realizar operaciones matemáticas básicas.

Incluye funciones para sumar, restar, multiplicar y dividir.
"""
def sumar(a, b):
    """Suma dos números."""
    return a + b
```

Dentro de una función: Para explicar qué hace la función, cuáles son sus argumentos, qué tipo de valor devuelve y cualquier otra información relevante sobre su uso, como posibles errores que pueda generar.  

```python
def calcular_promedio(lista_numeros):
    """
    Calcula el promedio de una lista de números.

    Args:
        lista_numeros (list): Una lista de números enteros o flotantes.

    Returns:
        float: El promedio de los números en la lista.
               Retorna 0.0 si la lista está vacía.

    Raises:
        TypeError: Si algún elemento de la lista no es un número.
    """
    if not lista_numeros:
        return 0.0
    suma = sum(lista_numeros)
    return suma / len(lista_numeros)
```

Dentro de una clase: Para describir el propósito de la clase, sus atributos principales y los métodos que ofrece.

```python
class Coche:
    """
    Representa un coche con marca, modelo y año de fabricación.
    """
    def __init__(self, marca, modelo, año):
        """
        Inicializa una nueva instancia de la clase Coche.

        Args:
            marca (str): La marca del coche.
            modelo (str): El modelo del coche.
            año (int): El año de fabricación del coche.
        """
        self.marca = marca
        self.modelo = modelo
        self.año = año

    def obtener_informacion(self):
        """
        Devuelve una cadena con la información del coche.
        """
        return f"{self.marca} {self.modelo} ({self.año})"
```

## Accediendo a los Docstrings

Una de las grandes ventajas de los docstrings es que puedes acceder a ellos directamente desde el intérprete de Python o desde tu código utilizando el atributo especial `__doc__`.

```python
print(sumar.__doc__)
print(calcular_promedio.__doc__)
print(Coche.__doc__)
print(Coche.obtener_informacion.__doc__)
```

Al ejecutar este código, se imprimirá el docstring que definiste para cada uno de estos elementos.

También puedes usar la función `help()` de Python, que muestra el docstring de un objeto de una manera más legible:

```python
help(sumar)
help(calcular_promedio)
help(Coche)
help(Coche.obtener_informacion)
```

## Importancia de los Docstrings

- **Claridad**: Ayudan a entender rápidamente qué hace un determinado bloque de código sin tener que leer toda su implementación.
- **Documentación Automática**: Herramientas como Sphinx pueden leer los docstrings de tu código y generar automáticamente documentación HTML o PDF de aspecto profesional.
- **Mantenibilidad**: Facilitan la comprensión del código cuando necesitas modificarlo o corregir errores en el futuro.
- **Uso en IDEs**: IDEs como Visual Studio Code a menudo muestran los docstrings cuando trabajas con funciones o clases, lo que te proporciona información útil al instante. Por ejemplo, al escribir el nombre de una función y abrir paréntesis, VS Code suele mostrar una ventana emergente con el docstring.
